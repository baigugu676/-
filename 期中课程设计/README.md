## 页面功能

任务一：四城切换、天数/百分比、四类分组显隐、按月份/降水日数排序、点击及键盘选月、明细统计、完整月度 CSV、当前视图 SVG、重置。

任务二：四城主城市选择、全年/月度筛选、气温/降水指标、多城市曲线、日最低至最高气温带、全年天气日历、点击联动到月份与日期、1–50 mm 关注阈值、四城对比与同日明细、逐日表、时段 CSV、趋势 SVG、重置。

任务一 CSV 始终导出当前城市全年所有分组，不受图例显隐与排序影响；任务二 CSV 导出当前主城市和当前月份/全年的记录。SVG 导出对应当前图表视图。

## 数据与研究口径

NASA POWER Daily API，2024-01-01 至 2024-12-31，成都、重庆、昆明、贵阳各 366 条，共 1,464 条，六项逐日指标。本次快照无缺测，保留了缺测处理逻辑和边界测试。

- 网格历史数据，非气象站现场实测，非实时天气或预报。
- 时间标准为 LST 本地太阳时，日界线与北京时间不同。
- 日降水按 `[0,0.1)`、`[0.1,10)`、`[10,25)`、`[25,+∞)` mm 分组，为本项目分析区间。
- 百分比除以当月全部有效降水日；隐藏分组后不重新归一化。
- 气温按有效逐日值求均值，降水按有效日量求和；-999 转为 null，不作为 0。
- 单一年份仅支持描述性比较，不推断多年气候趋势或因果关系。

来源与完整 URL 见 `数据/数据说明.md`。

## 可选开发复核

普通查看不需要以下工具。

```bash
# Python 标准库：复用原始快照整理、独立校验
python 工具/fetch_data.py
python 工具/validate_data.py

# 需要联网才重新下载；上游更新后需同步截图、结论与报告
python 工具/fetch_data.py --refresh

# 浏览器端到端验证；需要 Node.js 和可用的 Chromium
npm install --no-save playwright
npx playwright install chromium
node 工具/browser_check.cjs

# 报告生成；需要 python-docx 1.2.0
pip install python-docx==1.2.0
python 工具/build_report.py
```

需要本地 HTTP 服务时，在当前目录执行 `python -m http.server 8000`，再打开 `http://localhost:8000/入口.html`。Linux 可将 `python` 替换为 `python3`。

Windows 安装了 Microsoft Word 时，可运行 `powershell -ExecutionPolicy Bypass -File 工具/export_pdf.ps1` 导出 PDF。修改报告后请重新导出 PDF，并检查实际分页。

展示顺序与约 5 分钟演示脚本已写入报告最后一章。使用辅助工具形成的材料应由提交者理解、复核，并依课程要求如实说明。
